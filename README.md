# Coffee – страница «Управление меню» кофейни

Курсовая работа по ПМ.09 / МДК.09.01 «Проектирование и разработка веб-приложений».
Тема: «Разработка дизайна страницы «Управление меню» ресторана».

**Демо (только сайт, без сервера):** [coffee-u93j.vercel.app](https://coffee-u93j.vercel.app/)

- Сайт: React 19 + TypeScript 6.0 + Vite 8.
- Сервер: Node.js + Express 5, данные – в JSON-файле `server/data/db.json`.
- Админ-панель `admin.html`: вход по логину и паролю, добавление, изменение и удаление карточек меню,
  загрузка фото, стоп-лист, выбор позиции для баннера «Сейчас популярно».

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

| Адрес | Что это |
| --- | --- |
| http://localhost:5173/ | сайт |
| http://localhost:5173/admin.html | админ-панель (ссылка «Управление меню» в подвале сайта) |
| http://localhost:3001/api/menu | данные меню из базы в браузере |

**Вход в админ-панель:** логин `annakim`, пароль `21090803`.
Чтобы поменять, скопируйте `.env.example` в `.env` и впишите свои значения.

Одной командой собрать сайт и запустить его вместе с сервером на одном адресе
(например, для показа): `npm run build && npm start`, затем откройте http://localhost:3001/.

## Где лежат данные

- `server/data/db.json` – «база данных»: обычный JSON, его можно открыть в VS Code и посмотреть все позиции.
  Создаётся автоматически при первом запуске из `server/data/seed.json` (исходное меню).
- `server/uploads/` – фото, загруженные через админ-панель.

## API

| Метод и адрес | Вход | Что делает |
| --- | --- | --- |
| `GET /api/menu` | – | меню и позиция для баннера |
| `POST /api/login` | – | вход: `{ login, password }` → `{ token }` |
| `POST /api/logout`, `GET /api/me` | да | выход, проверка входа |
| `POST /api/menu` | да | добавить позицию (form-data, фото в поле `image`) |
| `PUT /api/menu/:id` | да | изменить позицию (form-data) |
| `PATCH /api/menu/:id` | да | изменить отдельные поля (JSON), например `{ "available": false }` |
| `DELETE /api/menu/:id` | да | удалить позицию и её загруженное фото |
| `PUT /api/popular` | да | позиция для баннера: `{ "id": "latte" }` |


## Публикация

сайт на Vercel показывает встроенное меню из `src/data/menu.ts`, а админ-панель работает при локальном запуске.
